# 域名与国内 IP 分流

## 启用

升级客户端和 daemon，并重新启动后台。在「分流规则」选择按规则，将以下规则放到最终 `final,proxy` 之前：

```text
geoip,cn,direct
final,proxy
```

已有明确代理例外、国内域名及自定义规则保留原顺序。`config/china-direct.rules` 和 `config/china-direct-full.rules` 已加入该兜底规则。已有用户配置不自动覆写；可以手工加入这条规则，或者导入更新后的规则文本。

规则按顺序首次命中。未入域名名单的 `smart.zeroiot.com` 走到 `geoip,cn` 后，客户端按需查询真实地址：命中国内 IPv4/IPv6 时直连，否则继续后续规则。已在前面命中的代理域名不发生本地分类解析。

## 格式与兼容

```text
geoip,cn,direct
geoip,cn,direct,no-resolve
ip-cidr,182.92.0.0/16,direct,resolve
ip-cidr6,2400::/12,direct,resolve
```

`geoip` 仅支持 `cn`，默认允许按需解析。原有三字段 `ip-cidr`、`ip-cidr6` 默认不主动解析；加 `resolve` 才触发解析。`no-resolve` 不主动查询，但可匹配前面的规则已经取得的解析结果。其他类型和未知选项报错，不静默忽略。

daemon 将规则作为不可变快照使用。等待 DNS 时不持有规则锁；更新后新决策使用新快照，已开始的决策继续使用原快照。解析后从触发查询的位置继续，不回头重跑已跳过的规则。

## 地址与 DNS

Fake-IP 先恢复原始域名，再统一决策。丢失的 Fake-IP 映射仍然拒绝。TCP、SOCKS UDP、HTTP 和 TUN 经由同一规则入口。

同一个响应可能包含国内外地址。按规则先后选择命中的地址集合；IP 规则决定直连时只使用这组地址拨号，不再解析或改连未获准地址。TCP 可在获准地址中尝试连接；UDP 使用其中第一个地址。直连失败不自动改变为代理。

代理仍传递原始域名，由服务器解析。HTTPS 的应用层原始域名、SNI 和证书验证不因选择真实 IP 而改变。纯数字 IP 请求直接匹配，不做反向 DNS。

分类和 Direct 复用 `Outbound` 的解析与源地址绑定：普通模式使用系统解析，Linux TUN 使用已配置的真实 DNS 和 uplink source，不能回退到未绑定出站。缺失对应出站地址族时不尝试该族。A/AAAA 并发查询，显式 DNS 支持 CNAME 和 UDP 截断后的 TCP 查询。

解析总预算为 3 秒，包括等待同域名的并发查询；失败、超时或无可用真实地址后继续后续规则。Fake-IP 和未指定地址不允许成为真实目标。最终动作由规则决定，DNS 失败不会自动直连。

每份出站配置共享最多 1,024 个缓存项，按域名和查询类型区分，并发查询合并。显式 DNS 使用地址记录及 CNAME 链的最短 TTL，最多缓存 300 秒，TTL=0 不延长；系统 API 不提供 TTL，短缓存 30 秒。失败或空结果短缓存 2 秒。取消查询不会永久锁住同域名；正在查询的缓存槽不会被容量驱逐。

应用新配置会建立新的出站策略和缓存，规则更新不缓存路由动作，因此不保留过期的分流结论。「DNS → 清理 DNS 缓存」清空真实解析缓存并清理过期 Fake-IP 映射，保留有效 Fake-IP 映射。

## 数据

国内 IP 使用 `crates/helios-routing/data/china-ip.txt` 的 2026-11-04 历史快照，共 9,651 个 IPv4/IPv6 网段。来源和 SHA-256 见同目录 README。数据编译进程序，启动不联网下载；IPv4/IPv6 分别合并区间后通过二分查找匹配。

更新软件时可以更新快照，本次不包含自动下载。IP 归属不是网站可访问性的保证，DNS 污染和 CDN 地域差异仍可能导致误判，应使用更前面的域名例外修正。

## 后台规则测试

规则页面保留无需 DNS 的即时预览。需要解析时点击「后台测试」，会把当前模式、未保存规则、目标和 TCP/UDP 发送给运行中的 daemon，使用其实际 DNS 与出站配置，显示动作、规则编号、真实解析结果、命中地址及 DNS 错误。测试不会保存或应用草稿，不验证网站 HTTP 可达性。

后台未运行时，域名 IP 分类没有确定结果；纯域名命中和数字 IP 仍可离线预览。输入变化后清除旧结果，过期异步响应不会覆盖新测试。

控制协议升级到版本 5，客户端、daemon 和 heliosctl 应一起更新。单条消息上限仍为 64 KiB；独立国内 IP 数据不经过控制接口传输。完整版的大域名文本仍可能超过限制，超限明确报错，不能把磁盘保存成功视为后台应用成功。
