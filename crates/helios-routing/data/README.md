# Mainland China IP snapshot

`china-ip.txt` contains the 9,651 mainland IPv4/IPv6 CIDRs previously bundled
in `config/china-direct-full.rules`, extracted without changing their contents.
The original snapshot was collected on 2026-11-04 from the local Clash Party
`geoip-cn.payload`. See `docs/14-china-direct-routing.md` for the original audit.
This is a historical snapshot, not a continuously updated country database.
